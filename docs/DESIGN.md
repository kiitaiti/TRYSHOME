# デザイン方針メモ（参考サイト分析と反映）

## 参考1：ykart.jp/reform（構成・デザインの主参考）— 実画面をPC 1366px / SP 390px で確認

| 観察した特徴 | TRYS HOME への反映 |
| --- | --- |
| ヘッダー：左に小さなタグライン＋ロゴ、中央にアイコン付きナビ、右に電話番号ブロックと相談ボタン | 同じ並び。右ブロックは「リフォームのご相談 / 042-719-0651」＋オレンジの「ご相談・お見積り」ボタン。SPはロゴ＋TEL＋MENU |
| ページ上部：暗い写真バナーに白の見出し、その下にパンくず | `PageHero` + `Breadcrumb` として全下層ページに統一 |
| 「REFORM.01」大見出し（頭文字だけオレンジ）＋角括弧のサブ見出し | `SectionTitle`（英字の::first-letterをオレンジ、日本語サブ見出し） |
| 分類ボタンのグリッド（灰色背景に白ボタン） | リフォーム詳細ページ冒頭のジャンプボタン、施工実績のカテゴリー絞り込み |
| 灰色帯＋オレンジ縦線の中見出し | `.bar-heading` を全ページで使用 |
| 「こんなお悩みはありませんか？」オレンジ帯＋チェック付きリスト、右に写真 | `TroubleBox` をトップ／メニュー／詳細で使用。左テキスト・右写真の2カラム |
| 「こんなに変わる！」黒帯＋点線枠＋BEFORE(黒)/AFTER(オレンジ)ラベル | `BeforeAfter`。CMSで両画像がある案件だけ表示 |
| 「事例集はこちら」の白抜き角丸ボタン、価格表 | 事例リンクは同型のアウトラインボタン。価格表は未提供のため「個別お見積り」の案内に置換 |
| 右端の固定ボタン群・SP下部の固定バー | PCは右側にLINE／お問い合わせ／電話、左側にInstagram／TikTokの固定タブ。SPは下部固定バー（電話 / LINE / フォーム） |
| セクションごとに白／薄灰／薄橙で区切る余白感 | 同様に交互配色。過剰な影・グラデーション・ガラス表現は不使用 |

## 参考2：yamani-g.co.jp（キャラクター配置・ロード演出）

- ロード画面で商品とキャラクターが動きながら "Now Loading" → フェードでトップへ。→ 家とスギトラの演出（`Loader.astro`）に置換
- キャラクターがセクションの端から顔を出す・見出しの横に立つ・吹き出しで一言 → `Sugitora` コンポーネントで各所に配置、吹き出し素材（「めっちゃ綺麗やん！」「TRYSにお任せ！」）を実績・CTA/FVに使用

## カラー・タイポグラフィ

- オレンジ `#F07E1A`（濃 `#D1670A`、淡 `#FFF4E8` / `#FFF9F3`）、黒ロゴと調和する暖色。灰 `#F5F5F5`、本文 `#333`
- 本文：Noto Sans JP、英字見出し：Montserrat（Google Fonts）
- 角丸 8–14px、影は控えめ、常時動く装飾なし（スギトラのふわふわ浮遊のみ、reduce-motion で停止）
