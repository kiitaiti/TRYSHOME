# デザイン方針と参考サイト分析

## 1. 参考サイト（BUDDICA）の分析

確認方法（2026-09-12）:
- HTML を取得して構造・リンクを解析（トップ / service / usedcar / insurance / store）
- 実ブラウザで表示し、PC（1440px）とスマートフォン（375px）のファーストビューを目視、各セクションの高さ・背景色・見出しのフォントサイズ・ボタンの色などを computed style で取得
- 注: ページ下部はスクロール連動アニメーションの影響でブラウザのスクリーンショットが取得できず、スクロール後の見た目は computed style と HTML 構造からの読み取りです

### 観察した特徴（BUDDICA）

| 観点 | 観察結果 |
| --- | --- |
| ヘッダー | 固定・透過。左ロゴ（オレンジ）、右に英語大文字のナビ（SERVICE / STOCK CAR …）。ホバーで日本語に切替。SP はロゴ＋ハンバーガーのみ |
| ファーストビュー | 全画面写真＋暗いオーバーレイ、白の極太日本語コピー（80px）。写真は人物・街並みで「感情」を先に見せる |
| セクション順序 | NEWS（薄グレー背景・リスト型）→ SERVICE（英語大見出し＋日本語リード）→ STOCK CAR（暗色背景の大きなバナー導線）→ WARRANTY 等サービス 3 列 → ECOSYSTEM → RECRUIT（大きな画像リンク）→ COMPANY（表）→ フッター |
| 英語と日本語 | 英語（Poppins 700・約 43px）がラベル、日本語見出しは 16〜26px で補足。日付は太字グレー小 |
| 写真 | 幅いっぱい・大きく。角丸ほぼなし、影なし |
| 導線 | NEWS / STOCK / SERVICE 各セクション末尾に丸アイコン付き「MORE」。在庫は外部（Goo-net / カーセンサー）へ誘導 |
| 色 | 白ベース、文字 #0d0d0d、補助背景 #f3f3f3、アクセントにオレンジ #ff6900、丸ボタン |
| SP | 1 カラム化、サービスカードは縦積み、ヒーロー写真は縦長トリミング |

## 2. TRYS MOTORS への反映

| BUDDICA の特徴 | 本サイトでの反映 |
| --- | --- |
| 透過固定ヘッダー＋英語ナビ | 同じ構成。英語＋日本語 2 段表記（日本語の意味が伝わるよう常時表示）。右端に「在庫車一覧（外部）」「お問い合わせ」 |
| 全画面写真のファーストビュー＋白の太コピー | 赤いクーペの写真を全幅に、下部を暗くして「あなたに合う一台を、一緒に。」を極太で配置。コピーのみを配置し、CTA はヘッダーと NEWS 以降へ |
| NEWS：薄グレー背景のリスト | 同型。日付・カテゴリータグ・タイトルの 3 列、最新 3 件、MORE 丸ボタン |
| 英語ラベル＋日本語見出し | 全セクション共通の `SectionHead`（赤の短いライン＋英語ラベル小、日本語見出しを主役に大きく） |
| STOCK CAR の暗色バナー | 黒背景に切り抜き車両（CX-8）を大きく置き、「カーセンサーで在庫車を見る」へ誘導。外部サイトである旨を明記 |
| サービスの大きな画像リンク | 写真＋文章の左右分割を交互に並べる（同じカードの繰り返しにしない） |
| 3 列の小項目 | 購入後サポート 6 項目をチェックアイコン付きの 3 列リストで |
| COMPANY の表 | ACCESS セクションに事業者情報の表＋地図 |
| 丸い MORE ボタン | 同型（赤丸＋矢印）。主要ボタンは角丸 4px の四角で「控えめ」 |
| 白×黒×赤 | 白 #FFFFFF / 本文 #222222 / 補助背景 #F5F5F3 / ブランド #D62828（赤） / 薄赤 #FDF1F1 |

流用していないもの: BUDDICA のロゴ・写真・コピー・実績数値・認定・企業情報・保証内容（437 項目等）・採用/FC/グッズなど TRYS MOTORS に存在しない事業。

## 3. トークン（`src/styles/global.css`）

- 色: `--c-brand #D62828`（ブランドカラーは赤。変更する場合はここだけ）
- フォント: Noto Sans JP（本文・見出し）、Poppins（英語ラベル・日付）
- コンテナ: 1160px、狭幅 820px、余白 `--section-y: clamp(64px, 9vw, 120px)`
- 角丸: 4px（ボタン）/ 8px（カード・写真）。影は使用しない
- モーション: スクロールで軽いフェードインのみ。`prefers-reduced-motion` では無効
