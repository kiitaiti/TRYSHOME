# microCMS 設定（API・フィールド定義・Webhook）

サービスを1つ作成し、以下の **2つの API（リスト形式）** を作成します。
フィールドID は本ドキュメントの通りにしてください（コード側 `src/lib/microcms.ts` が参照します）。

## API 1：お知らせ `news`

- API 名：お知らせ
- エンドポイント：`news`
- 型：リスト形式

| 表示名 | フィールドID | 種類 | 必須 | 備考 |
| --- | --- | --- | --- | --- |
| タイトル | `title` | テキストフィールド | ✔ | |
| サムネイル画像 | `thumbnail` | 画像 | | 任意。無い場合は一覧・詳細ともサムネイル無しで表示 |
| カテゴリー | `category` | セレクトフィールド | ✔ | 選択肢例：`お知らせ` `施工情報` `キャンペーン` `休業案内`（複数選択OFF推奨） |
| 本文 | `body` | リッチエディタ | ✔ | 見出し・リスト・画像・リンク可 |
| 公開日 | `date` | 日時 | ✔ | 一覧の並び順と表示日付に使用（未入力時は microCMS の公開日時を使用） |

## API 2：施工実績 `works`

- API 名：施工実績
- エンドポイント：`works`
- 型：リスト形式

| 表示名 | フィールドID | 種類 | 必須 | 備考 |
| --- | --- | --- | --- | --- |
| タイトル | `title` | テキストフィールド | ✔ | 例「浴室をユニットバスへ交換」 |
| メイン画像 | `mainImage` | 画像 | ✔ | 一覧カード・詳細の主画像（横長推奨、4:3で表示） |
| 施工カテゴリー | `category` | セレクトフィールド | ✔ | **選択肢は次の値と完全一致させる**：`水回り` `内装` `屋根外壁` `エクステリア` `大工・造作` `住宅設備`（複数選択ON） |
| 施工エリア | `area` | テキストフィールド | | 任意。例「町田市」 |
| 建物種別 | `buildingType` | テキストフィールド | | 任意。例「戸建」「マンション」 |
| 工事内容 | `workContent` | テキストフィールド | ✔ | 一覧・詳細のデータ表に表示 |
| 工期 | `period` | テキストフィールド | | 任意。例「約2週間」 |
| 費用 | `cost` | テキストフィールド | | 任意。未入力時は「個別にお見積り」の案内を表示 |
| Before画像 | `beforeImage` | 画像 | | 任意 |
| After画像 | `afterImage` | 画像 | | 任意。**Before と After が両方ある場合のみ比較表示**。片方だけの場合は「施工写真」に並びます |
| 追加写真 | `gallery` | 複数画像 | | 任意 |
| 本文 | `body` | リッチエディタ | | 任意 |
| トップページに掲載 | `featured` | 真偽値 | | ON の実績をトップページに最大6件表示（ON が3件未満のときは新着順で表示） |

施工カテゴリーの選択肢を増やす場合は `src/data/reform.ts` の `worksCategory` にも同じ値を追加してください（絞り込みページが生成されます）。

## API キー

- サービス設定 → API キー → 作成。権限は **GET のみ** で十分です
- キーは Netlify の環境変数 `MICROCMS_API_KEY` にのみ登録します。GitHub や JavaScript には含めません
- サービスID（`https://xxxx.microcms.io` の `xxxx`）を `MICROCMS_SERVICE_DOMAIN` に登録します

## Webhook 設定（更新したら Netlify を自動で再ビルド）

microCMS で公開・更新・削除したときに Netlify の再ビルドを起動する設定です。`news` と `works` の **両方の API で** 行います。

### Netlify 側：Build hook を作成
1. Netlify → Site configuration → Build & deploy → **Build hooks** → **Add build hook**
2. 名前：`microCMS`、Branch：`main` → Save
3. 表示された URL（`https://api.netlify.com/build_hooks/xxxxxxxx`）をコピー

### microCMS 側：Webhook を登録
1. microCMS → 対象 API（`news`）→ **API 設定 → Webhook** → **追加**
2. サービスに **Netlify** を選択（無い場合は「カスタム通知」で URL を指定）
3. 上でコピーした Build hook URL を貼り付け
4. 通知タイミング：以下をすべて ON
   - コンテンツの公開時・更新時
   - コンテンツの非公開時
   - コンテンツの削除時
   - （予約公開を使う場合）公開予約の実行時
5. 保存 → `works` API でも同様に設定

### 動作確認
1. microCMS で `news` にテスト記事を追加して「公開」
2. Netlify → Deploys に新しいビルドが始まることを確認（1〜3分で反映）
3. 記事を「削除」→ 再びビルドが走り、サイトから消えることを確認

## 画像について

- microCMS の画像は imgix 経由で配信され、サイト側で `?w=…&fm=webp` を付けて自動的に軽量化・WebP 化します
- 元画像は長辺 2000px 程度・2MB 以内を目安にアップロードしてください
