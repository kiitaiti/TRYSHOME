# 更新マニュアル（お知らせ・施工実績）

日々の更新は **microCMS の管理画面だけ** で完結します。GitHub やコードの操作は不要です。
公開ボタンを押すと自動でサイトが再ビルドされ、1〜3分ほどで反映されます。

## お知らせを投稿する

1. microCMS にログイン → 左メニュー **お知らせ（news）** → **追加**
2. 各項目を入力
   - **タイトル**：例「夏季休業のお知らせ」
   - **サムネイル画像**：任意（無くてもOK）
   - **カテゴリー**：一覧から選択
   - **本文**：リッチエディタで入力。見出し（H2/H3）、箇条書き、画像、リンクが使えます
   - **公開日**：一覧に表示される日付。並び順もこの日付で決まります
3. 右上の **公開** を押す（下書き保存だけではサイトに出ません）
4. 数分後、トップページの「お知らせ」（最新3件）と `/news/` に表示されます

編集・削除：該当記事を開いて修正 → **公開**。削除は「…」メニュー → 削除。どちらも自動で反映されます。

## 施工実績を投稿する

1. 左メニュー **施工実績（works）** → **追加**
2. 各項目を入力
   - **タイトル**（必須）：例「浴室をユニットバスへ交換」
   - **メイン画像**（必須）：一覧のカードと詳細の一番上に出ます。横長の写真がきれいに収まります
   - **施工カテゴリー**（必須）：`水回り` `内装` `屋根外壁` `エクステリア` `大工・造作` `住宅設備` から選択（複数可）。絞り込みと、各リフォームページの「施工実績」に使われます
   - **工事内容**（必須）：一文で。例「ユニットバスへの交換・脱衣所の床張り替え」
   - **施工エリア／建物種別／工期／費用**：分かる範囲で。**空欄の項目は表示されません**（空の見出しは出ません）
   - **Before画像／After画像**：両方入れると「こんなに変わる！」の比較表示になります。片方だけのときは施工写真として並びます
   - **追加写真**：何枚でも。詳細ページの「施工写真」に並びます
   - **本文**：工事のポイントや工夫など（任意）
   - **トップページに掲載**：ON にするとトップページの「施工実績」に出ます（最大6件、新しい順）
3. **公開** を押す

## 注意事項

- **お客様の許可**を得た写真のみ掲載してください。住所が特定できる表札・車のナンバー等は写らないように
- **費用**は「概算」「〜」など表現を確認のうえ入力してください。空欄なら「個別にお見積り」と案内されます
- 写真は長辺 2000px 程度、1枚 2MB 以内が目安です（サイト側で自動的に軽量化されます）
- タイトル・本文に「保証」「満足度」「件数」などを書く場合は、根拠のある内容にしてください

## 会社情報・リフォームメニュー・FAQ を変える場合

これらは microCMS ではなくコードで管理しています（変更頻度が低く、正確性を保つため）。

| 変更したい内容 | ファイル |
| --- | --- |
| 住所・電話・許可番号・対応エリアなど | `src/data/site.ts` |
| リフォームメニューの分類・お悩み・工事内容・写真 | `src/data/reform.ts` |
| 選ばれる理由・施工の流れ・FAQ | `src/data/content.ts` |
| プライバシーポリシー | `src/pages/privacy.astro` |

変更後に GitHub の `main` へ push すると Netlify が自動で再ビルドします。
